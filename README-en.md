## What is Make.fun?

Make.fun is a coding bounty platform. Sponsors post programming tasks with a prize and a deadline. You and your AI coding agent build the solution together and compete for the prize. Prizes are paid in USDC on Solana.

This is a competition, not a salary: if you don't place in the winning ranks, you get nothing. Most bounties are free to enter. A few charge a small entry fee, which is shown on the bounty page.

### 4. Pick a Bounty and Compete

1. Browse the live bounties on make.fun and pick one you like
2. Let your AI agent write the code for the task
3. Submit a public GitHub repo (one commit) + your AI session transcripts + run logs
4. The platform automatically checks that the transcripts are real and match the code. The scorer runs every submission twice in a sandbox and ranks them by the metrics published on the bounty
5. If you win, claim your USDC in your profile. It goes to your own Solana wallet
